# lanbox 网页「管理」与 memos 风格改版

日期：2026-11-26
状态：已实现（提交 `feat(web): 「用户管理」改为「管理」，界面风格参考 usememos/memos`）
范围：只改前端呈现层；不改 `/api/*` 契约、存储格式、认证语义与 CSP。

## 1. 目标

1. 把顶栏与管理入口的「用户管理」统一改称**「管理」**，语义覆盖管理页里的用户与设置两个分区。
2. 界面风格参考 [usememos/memos](https://github.com/usememos/memos)：暖灰画布、白色浮层卡片、克制的描边与阴影、无重音色（主按钮用近黑/近白反色）、左侧栏 + 单列时间线。

## 2. 为什么仍然是手写 ES 模块

`docs/superpowers/specs/2026-11-26-web-vue-theme-design.md` 里选定的 Vue + Vite 方案没有落地（`frontend/` 目录与 `Makefile` 的 `web` 目标都不存在）。本次沿用现状：`web/` 下 8 个 ES 模块直接被 `//go:embed all:web` 打进二进制，`go build` 不依赖 Node，CSP 保持 `default-src 'self'`（无内联脚本、无 `unsafe-eval`、无外链字体）。若将来要做 Vue 改版，本文的令牌与结构可直接复用。

## 3. 设计令牌

新增 `web/style.css` 顶部的两套令牌，取值对齐 `@usememos/ui` 的 `tokens.css`（`--mu-*`），改名为更短的语义名：

| 令牌 | 含义 |
|---|---|
| `--canvas` / `--surface` / `--well` | 画布 / 卡片 / 内凹（输入框、分段控件底） |
| `--hover` / `--selected` | 悬停 / 选中 |
| `--line` / `--edge` | 分隔线 / 控件描边 |
| `--text` / `--text-2` / `--text-3` | 正文 / 次要 / 最弱 |
| `--primary` / `--primary-hover` / `--on-primary` | 主按钮（亮色近黑、暗色近白） |
| `--accent` / `--selection` | 链接与选区（唯一彩色强调） |
| `--success` / `--success-soft`、`--warning*`、`--danger*` | 语义色 |
| `--radius-*`、`--space-*`、`--control-*`、`--icon-*`、`--dur`、`--ease` | 与主题无关的尺寸/动效 |

主题挂在 `:root[data-theme='light'|'dark'|'paper']` 上，各自声明 `color-scheme`，原生控件与滚动条随之切换。`light` / `dark` 取自 `@usememos/ui` 的 `tokens.css`；`paper` 是 memos 自带的暖色主题，取值对齐其 `web/src/themes/paper.css`（暖纸画布、暖墨主按钮），侧栏主题选择器对应 memos 的「跟随系统 / 浅色 / 深色 / 纸张」四档。

## 4. 布局

```
┌──────────┬─────────────────────────────────┐
│ 侧栏/图标栏│ 顶栏（视图标题 + 实时状态）        │
│ 品牌      ├─────────────────────────────────┤
│ 视图/计数  │ 发布区（输入 + 附件 chip + 进度）  │
│ 搜索      │ 时间线（按日分组）…               │
│ 外观四档   │                                 │
│ 账号      │                                 │
└──────────┴─────────────────────────────────┘
```

- 侧栏固定 264px（≤900px 收窄到 240px）；桌面端可收成 **68px 图标栏**（标题旁的按钮切换，偏好存 `localStorage['lanbox.sidebar']`，由 `theme-boot.js` 在首帧前应用）；`≤720px` 改为抽屉式，由顶栏汉堡按钮开合，配半透明遮罩。
- 图标栏保留品牌、视图（带数量角标）、搜索入口、外观四档与账号操作，文字用 `title` 补充；点搜索图标会展开侧栏并聚焦输入框。
- 内容列 `max-width: 720px` 居中，与 memos 的时间线同宽。
- 顶栏 `sticky` + `backdrop-filter`，滚动时只留 1px 描边；默认视图不显示标题文字，只在搜索 / 未取走筛选时显示「搜索结果 / 未取走」。侧栏收合按钮用 14px 单箭头，避免抢视觉。
- 管理页**占满主内容区**（不再从右侧滑出，左侧栏保留可见可用）：顶栏 + 用户/设置两个分区，正文 `max-width: 1040px` 居中，≥1000px 时设置卡片两列；窄屏单列、左侧栏收起。点侧栏的视图/搜索会退出管理页回到列表。

## 5. 组件约定

| 组件 | 约定 |
|---|---|
| 卡片（`.memo`） | 作者头像（首字母 + 稳定色相）、来源 IP、相对时间（`title` 给绝对时间；超过一天只显示时分，日期由分组行给出）、正文、附件表、底部轻量操作 |
| 日期分组 | 按本地日期插入分隔行：今天 / 昨天 / `M 月 D 日`（跨年带年份）；跨零点后自动重排 |
| 附件行 | 目录前缀 + 文件名 + 大小/下载次数；操作（下载/删除）在「宽屏 + 有鼠标」时 hover 显现，触屏与窄屏常显 |
| 发布区 | 左侧当前用户头像 + 自适应高度输入框（最高 240px）、`Ctrl/⌘+Enter` 发送、拖拽整卡高亮、待上传 chip 可逐个移除 |
| 管理页 | 占据主内容区（左侧栏保留可导航）、背景滚动锁定、顶部标题 + 关闭按钮、`Escape` 关闭；切换分区回到顶部；窄屏时占满全屏 |
| 反馈 | `toast()` 替代 `alert()`；`confirmDialog()/promptPassword()` 替代 `confirm()/prompt()`，危险操作用红色主按钮 |
| 空状态 | 三种文案：还没有内容 / 没有匹配 / 未取走为空 |
| 设置页 | 「保存设置」吸附在页面底部，长表单无需滚到最末；用户分区限宽 760px，设置分区宽屏两列 |

## 6. 主题切换

- 四档：跟随系统 / 亮色 / 暗色 / 纸张，存 `localStorage['lanbox.theme']`（值为 `system` / `light` / `dark` / `paper`）。
- `web/theme-boot.js` 是 `<head>` 里的同步普通脚本，在任何绘制之前把偏好解析成 `data-theme`（`system` 按系统偏好落成 `light` 或 `dark`）、写入 `data-sidebar`（`wide` / `rail`），并同步 `<meta name="theme-color">`，因此刷新不闪屏、侧栏不会先宽后窄、手机浏览器地址栏颜色跟随。
- `ui.js` 的 `initTheme()` 监听系统主题变化，切换时同步 `aria-checked` 与 `theme-color`。
- 侧栏四档控件排成两列两行（≤480px 收成四个图标），避免「跟随系统」在 264px 侧栏里换行。

## 7. 侧栏计数的取舍

列表是按当前筛选从服务端分页拉回的，**其他视图的准确总数无从得知**。因此只在当前视图那一行显示数量（例如「未取走 3」），而不是两行都标数字 —— 否则切换筛选后会出现「全部 3」而实际有 5 条这种自相矛盾的展示。

## 8. 已知的边界与后续

- 时间线按本地日期分组；页面停留时每 30 秒原地刷新相对时间，跨零点重建分组（不打断 hover/focus）。
- 没有引入 Markdown 渲染（README 的「不做的事」明确不渲染富文本）。
- `web/` 是手写源码，没有构建步骤，因此不需要「改完记得重新构建」的纪律；反向代价是无法用 SFC 与 scoped CSS。

## 9. 验收

在 360/390/720/721/800/1000/1440 宽度、亮色 / 暗色 / 纸张三套主题下用无头 Chrome 逐屏核对，控制台无异常。覆盖：登录页、时间线、日期分组（今天 / 昨天 / 10 月 26 日）、超过一天只显示时分、未取走筛选、搜索结果为空、附件 hover、上传进度、拖拽高亮、侧栏收成图标栏及刷新保持、图标搜索展开并聚焦、移动端侧栏抽屉、管理页占满主内容区（左侧栏保留、用户/设置、宽屏两列、切换回顶部、`Escape` 关闭与焦点返回、侧栏切视图自动退出）、重置密码对话框、删除确认、登出返回登录页。
